NILE CROWN TRAVEL
=================
English: index.html

The Admin Dashboard lets you edit trip titles, prices, descriptions and image URLs in a browser interface.
Current browser editor saves changes in localStorage on the device/browser being used.

To make edits visible to ALL website visitors online, the next deployment step is to connect the dashboard to a hosted database/backend and publish the website on a domain.
